# 💰 Personal Expense Tracker

A simple Personal Expense Tracker built using Python and MySQL.

## Features

✅ Add Expense
✅ View Expenses
✅ Search Expense by Category
✅ Delete Expense
✅ Exit

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Database

Import the `database.sql` file into MySQL before running the project.

## How to Run

1. Clone the repository.
2. Import database.sql into MySQL.
3. Update MySQL username and password in expense_tracker.py.
4. Run:

python expense_tracker.py
